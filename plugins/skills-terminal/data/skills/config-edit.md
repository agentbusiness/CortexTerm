Edit a configuration file: inspect its current revision, preview one change, validate and verify.

Use `config` with action `inspect` and the actual file path. It reads this runner's machine. For an SSH target, use that target's runner or its editor; never substitute a local path.

Read the relevant section. The result gives line numbers, `sha256`, format and validation. Line numbers are display only. Redacted values cannot be edited by the model. A clipped result needs another bounded inspect.

For one non-secret change, call `config` with action `preview`, path, `expected_sha256` copied from inspect, exact `old_text` and replacement `new_text`. The old text must occur once. Include enough nearby text to identify it. Keep unrelated settings.

The app shows the diff and offers the generated command. A preview has not changed the file. The person runs Apply through the normal risk checks. Do not rewrite or run its command yourself.

A valid parse does not prove the service accepts the settings. Use the product's validator before a user-run reload, then check the intended behavior and logs. Apply returns a private backup path. Inspect the current revision before restoring it. Administrator files, secrets, hard links and unsupported metadata need the editor. macOS ACLs and extended attributes are preserved.
